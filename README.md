# 📖 토론벗 — 독서토론 검증 플랫폼

> 발췌문 안에서만 말하게 하고, 인용은 코드로 확인합니다.

AI에이전트연수 2회차 「독서토론」 워크플로의 서비스화 데모입니다.
발췌문을 등록하면 챗봇용 **프롬프트 카드**를 만들어 주고, 챗봇이 만든 논제·근거카드·토론 로그를 붙여 넣으면 **모든 인용을 코드로 검증**해 배지 리플레이와 리포트로 보여줍니다.

## 사용 흐름

1. **발췌문** — 저작권 확인 3종 통과 후 등록. 문단 번호 `[1]~[n]` 자동 부여
2. **프롬프트 카드** — 카드 5종(업로드 확인·논제·근거카드·활동지·토론규칙)을 복사해 내 챗봇(ChatGPT·Claude·Gemini 등)에 붙여넣기
3. **인용 검증** — 챗봇 결과·토론 로그를 붙여 넣으면 인용 전수 대조
4. **배지 리플레이** — 토론을 채팅으로 재생, 인용마다 ✓ 일치 / ~ 유사 / ✗ 없음 배지
5. **리포트** — 판정표·diff 대조·환각 인용 수업 활용 가이드, md 다운로드

상단의 **▶ 데모 데이터 불러오기**를 누르면 동물농장 샘플 발췌문과 환각 인용이 섞인 샘플 토론 로그로 전 과정을 바로 체험할 수 있습니다.

## 원칙

- **생성은 AI에게, 검증은 코드에게, 판정은 사람에게.** 검증 엔진은 LLM을 쓰지 않는 결정적 문자열 대조입니다(일치 / 유사도 80% 이상 / 없음). 같은 입력이면 항상 같은 결과가 나옵니다.
- **서버 없음.** 모든 데이터는 브라우저 안에만 있습니다(localStorage). 발췌문은 외부로 전송되지 않습니다.
- **승패 판정 기능이 없습니다.** 의도된 부재입니다.

## 실행

정적 파일 하나입니다. `index.html`을 브라우저로 열거나, GitHub Pages로 바로 서빙됩니다.
